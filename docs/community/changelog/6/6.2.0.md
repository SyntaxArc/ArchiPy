# 6.2.0 — 2026-11-23

[← 6.2.1](6.2.1.md) | [6.1.2 →](6.1.2.md) | [↑ 6.x series](index.md)

## Added

### Adapters - Redis

- **Redis 8.10 Command Families** - Expose the Redis 8.10 commands on the sync and async adapters.
    - Move list elements with `lmovem` and `blmovem`
    - Count set combinations with `sdiffcard` and `sunioncard`, including a `limit`
    - Bound stream replies with `max_count` and `max_size` on `xread` and `xreadgroup`
    - Return grouped field values with the preview `COLLECT` aggregation and its collection controls
    - List index aliases with `list_aliases`
- **redis-py 8.2 Command Support** - Add typed access to the redis-py 8.2 command families on both adapters.
    - Set-member expiration: `saddex`, `sexpire`, `spexpire`, `sexpireat`, `spexpireat`, `sttl`, `spttl`,
      `sexpiretime`, `spexpiretime`, and `spersist`
    - Sorted-set moves: `zmove`, `bzmove`, and `zmovemember`
    - Bitmap positions and key eviction flags: `bitrangeintarray`, `bless_get`, `bless_set`, `bless_clear`, and
      `bless_scan`
    - Client list iteration with `client_list_iter`, Count-Min Sketch cell sizing, and node backup commands
    - Shard channel publishing with `spublish`
- **Search Score Explanations** - Add `hybrid_search` with `explain_score` to both Search handles.
  [#641](https://github.com/SyntaxArc/ArchiPy/issues/641), [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)
- **Client-Side Caching** - Sync standalone and cluster adapters accept redis-py `CacheConfig` and a
  `MetadataResolver`; async cluster adapters accept an `AsyncMetadataResolver`. Client-side caching requires
  explicit RESP3. [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)

### Configs - Redis

- **Connection Options** - Add `UNIX_SOCKET_PATH` for standalone Unix sockets, `RETRY.FAIL_FAST_MISSING_SOCKET`, and
  `CLUSTER.TOPOLOGY_REFRESH_MIN_INTERVAL`. [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)
- **Protocol Negotiation** - Set `PROTOCOL` to `None` to let redis-py negotiate RESP3 and fall back to RESP2 when the
  server rejects `HELLO`. The default remains explicit RESP3.
  [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)

## Changed

### Adapters - Redis

- **Search Aggregation Fields** - `AggregationDTO.reduce_function` now accepts only `COUNT` or `COLLECT`. Use it with
  `collect_fields`, `collect_sort_by`, `collect_sort_direction`, and `collect_limit`.
  [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)
- **Sentinel Lifecycle** - Sentinel adapters use `replica_for` and close their Sentinel discovery pools on `close()`.
  [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)

## Fixed

### Adapters - Redis

- **Search COLLECT Aggregation** - Load reducer fields before grouping so `COLLECT` returns the requested values.
  [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)

## Tests

### Tests - Redis

- **Redis Capability Coverage** - Add sync and async scenarios for the Redis 8.10 and redis-py 8.2 commands, Search
  aggregation, and client-side caching against Redis 8.12.
  [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)
- **Container Image Retries** - Retry transient Docker Hub pulls with backoff on 429 and 5xx responses before a
  container starts. [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)

### Tests - Elastic

- **APM Database Span** - Assert the native database span of the Elasticsearch client, matching APM Server 9.5.7.
  [#642](https://github.com/SyntaxArc/ArchiPy/pull/642)
