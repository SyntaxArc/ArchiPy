# 6.1.0 — 2026-11-23

[← 6.0.1](6.0.1.md) | [↑ 6.x series](index.md)

## Changed

- **Optional Imports** - On Python 3.15, core helpers and adapters defer more configuration and error imports until
  use. Python 3.14 keeps eager imports. Error classes work without the gRPC extra.
  [#634](https://github.com/SyntaxArc/ArchiPy/pull/634)
- **Documentation Navigation** - The redesigned homepage, task-based tutorial navigation, and browsable API index make
  it easier to find common tasks and reference pages. Layouts adapt to mobile screens and dark mode.
  [#637](https://github.com/SyntaxArc/ArchiPy/pull/637)
- **Documentation Build** - One native Zensical configuration builds the site. API reference pages contain less
  duplicated content, search has fewer duplicate entries, and legacy URLs redirect to their current pages.
  [#632](https://github.com/SyntaxArc/ArchiPy/pull/632)

## Fixed

- **Custom Settings Providers** - Registered providers still control error localization after global configuration
  loads. [#634](https://github.com/SyntaxArc/ArchiPy/pull/634)
- **Read the Docs 404 Page** - Missing pages load their styles and provide working search and recovery links.
  [#636](https://github.com/SyntaxArc/ArchiPy/pull/636)

## Tests

- **Import and Documentation Checks** - Added fresh-process coverage for optional imports, strict documentation
  builds, and runnable examples for Redis caching, Redis TLS, and database migration retries.
  [#634](https://github.com/SyntaxArc/ArchiPy/pull/634) [#632](https://github.com/SyntaxArc/ArchiPy/pull/632)
