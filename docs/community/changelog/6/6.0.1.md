# 6.0.1 — 2026-11-22

[← 6.1.0](6.1.0.md) | [6.0.0 →](6.0.0.md) | [↑ 6.x series](index.md)

## Changed

### Helpers - Startup Imports

- **Application Bootstrap** - On Python 3.15, `AppUtils` loads FastAPI and gRPC only when their corresponding
  helpers are used. Importing application utilities works with either framework extra absent.
- **Decorators and Rate Limits** - On Python 3.15, lightweight decorator imports defer tracing, metrics, and gRPC
  rate-limit modules. In-memory rate-limit stores defer the server interceptors.
- **Error Helpers** - On Python 3.15, resolving an error no longer loads global application settings. Exception
  capture loads those settings when called.

### Configs - Section Imports

- **Configuration Templates** - On Python 3.15, importing an individual template loads its settings section on demand.
  Existing import paths and class identities are preserved. Python 3.14 continues to use eager imports.

### Models - Error Types

- **Transport SDKs** - Error models no longer load the gRPC or Keycloak SDK. Existing error codes, HTTP and gRPC
  status values, and localized messages are preserved.

## Tests

- **Import Coverage** - Fresh-process scenarios cover import timing, optional frameworks, and error status values
  on Python 3.14 and 3.15.
