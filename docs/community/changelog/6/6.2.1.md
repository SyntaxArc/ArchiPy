# 6.2.1 — 2026-11-24

[← 6.2.0](6.2.0.md) | [↑ 6.x series](index.md)

## Tests

### Tests - Redis

- **Container Image Source** - Pull the Redis test container from the official `redis:8.12.0-alpine` Docker Hub image instead
  of the GHCR mirror.

## Chore

### Chore - Tooling

- **Lint Rule Name** - Rename the `ty` ignore-comment rule to `unknown-rule-in-ignore-comment` so `make lint` passes with
  `ty` 0.0.109.

## Dependencies

### Dependencies - Minimum Versions

- **Lockfile Alignment** - Raise the minimum versions of the direct dependencies to match `uv.lock`.
    - `grpcio` and `grpcio-health-checking` to `1.85.4`
    - `boto3` and `boto3-stubs` to `1.44.10`
    - `pydantic-ai-slim` to `2.73.0`
    - `coverage` to `7.17.5` and `ty` to `0.0.109`

### Dependencies - Lockfile

- **Transitive Updates** - Refresh `botocore`, `filelock`, `jwcrypto`, `logfire-api`, `packaging`, `pydantic-graph`,
  `python-discovery`, and `virtualenv`.
