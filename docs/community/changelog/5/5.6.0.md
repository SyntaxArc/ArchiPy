# 5.6.0 — 2026-09-30

[← 5.7.0](5.7.0.md) | [5.5.2 →](5.5.2.md) | [↑ 5.x series](index.md)


## Added

### Configs - OpenTelemetry

- **FastAPI operation spans flag** - Added `OTEL.FASTAPI_OPERATION_SPANS_ENABLED` (default `true`).
    - Controls FastAPI child spans for dependencies, the endpoint, serialization, and background tasks
    - Only applies when `OTEL.TRACES_ENABLED` is true

### Helpers - FastAPI

- **`FastAPIUtils.build_otel_telemetry_config`** - Builds the `telemetry` argument for `FastAPI(...)` from ArchiPy
  OTel settings.
    - Uses ArchiPy tracer and meter providers; a signal without a real provider is disabled
    - `auto_configure` and FastAPI log records stay off, since ArchiPy owns the exporters and logging handler
    - `OTEL.FASTAPI_EXCLUDED_URLS` patterns are matched as regular expressions against the request path

## Changed

### Helpers - FastAPI

- **Native FastAPI telemetry** - `AppUtils.create_fastapi_app` now enables FastAPI's built-in OpenTelemetry support
  instead of `FastAPIInstrumentor`.
    - The HTTP duration metric is now `http.server.request.duration` (seconds), replacing `http.server.duration`
      (milliseconds); update dashboards and alerts
    - Span names stay `GET /path`
- **`archipy[otel-fastapi]` extra** - Now requires `fastapi>=0.142.2` instead of
  `opentelemetry-instrumentation-fastapi`.

## Removed

### Helpers - FastAPI

- **`FastAPIUtils.setup_otel`** - FastAPI reads `telemetry` only in its constructor, so it cannot be applied to an
  existing app.
    - Migrate custom apps to `FastAPI(telemetry=FastAPIUtils.build_otel_telemetry_config(config))`

## Tests

### Tests - OpenTelemetry

- **HTTP duration metric name** - The FastAPI BDD step now asserts `http.server.request.duration`.

## Dependencies

- **FastAPI** - Raised the `fastapi` extra floor to 0.142.2.
- **Lockfile refresh** - `boto3`, `boto3-stubs`, and `botocore` 1.43.105, `charset-normalizer` 3.5.2, `filelock`
  4.0.7, `googleapis-common-protos` 1.75.5, `platformdirs` 4.12.2, `virtualenv` 21.14.1.
    - Dropped `opentelemetry-instrumentation-fastapi`, `opentelemetry-instrumentation-asgi`, and `asgiref` from the lock
