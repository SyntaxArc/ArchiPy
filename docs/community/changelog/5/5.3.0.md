# 5.3.0 — 2026-09-14

[← 5.4.0](5.4.0.md) | [5.2.4 →](5.2.4.md) | [↑ 5.x series](index.md)

## Added

### Configs - BaseConfig

- **APP_NAME identity field** - Top-level `APP_NAME` is now a built-in
  `BaseConfig` setting (env: `APP_NAME`). On `set_global()`, `customize()`
  fills nested identity defaults when they are still unset or placeholders:
    - `OTEL.SERVICE_NAME` when `None`
    - `FASTAPI.PROJECT_NAME` when `"project_name"`
    - `AUTH.JWT_ISSUER` when `"your-app-name"`
    - `TEMPORAL.CLIENT_IDENTITY` when `None`
    - Explicit nested env values (`OTEL__SERVICE_NAME`, etc.) always win

## Tests

### Tests - Configs

- **APP_NAME sync BDD** - Scenarios assert nested identity fill on
  `set_global` and that explicit `OTEL.SERVICE_NAME` overrides are kept.
