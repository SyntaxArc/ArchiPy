# 5.27.0 — 2026-11-02

[← 5.26.1](5.26.1.md) | [5.28.0 →](5.28.0.md) | [↑ 5.x series](index.md)

## Added

### Adapters - SQLAlchemy

- **Savepoints for Nested Atomic Calls** - `sqlalchemy_atomic` and the PostgreSQL, MySQL and SQLite shortcuts accept `savepoint=False`.
    - `savepoint=True` runs a nested call in a savepoint; a caught failure rolls back only that savepoint and the outer transaction stays committable
    - Savepoints stack: a failure at one level rolls back that level only, and a parent level can catch it and continue
    - Default `savepoint=False` keeps the 5.26.1 behavior: a nested failure rolls back the whole transaction and the outer block raises `DatabaseTransactionError`
    - A `savepoint=False` call anywhere in the chain still aborts the whole transaction, even inside a savepoint
    - StarRocks has no `SAVEPOINT` support: `starrocks_sqlalchemy_atomic` takes no `savepoint` argument, and `sqlalchemy_atomic("starrocks", savepoint=True)` raises `InvalidArgumentError`
