# 5.18.1 — 2026-10-20

[5.18.0 →](5.18.0.md) | [↑ 5.x series](index.md)

## Fixed

### Helpers - Decorators

- **Import Without Cache Extra** - `import archipy.helpers.decorators` no longer fails with `ModuleNotFoundError: No module named 'cachetools'` when the `cache` extra is not installed.
    - `cachetools` is imported lazily, so `retry`, `timeout`, `singleton`, `trace_class` and the other decorators load without it
    - Calling `ttl_cache` without `cachetools` raises `ConfigurationError` with a hint to install `archipy[cache]`

## Tests

### Tests - Helpers

- **Decorator Import Scenario** - Added a BDD scenario that imports `archipy.helpers.decorators` with `cachetools` blocked.

## Chore

### Chore - Tests

- **Unused Import** - Removed an unused import from the application utils steps.
