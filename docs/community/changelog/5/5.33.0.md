# 5.33.0 — 2026-11-21

[← 5.32.0](5.32.0.md) | [↑ 5.x series](index.md)

## Added

### Configs - Nested Settings

- **Grouped Settings** - Related settings now live in nested groups of their section. Groups reject unknown keys, use
  UPPER_CASE fields, and name every on/off switch `IS_ENABLED`. Set them in code or with the `__` delimiter, for
  example `REDIS__TLS__IS_ENABLED=true`. [#622](https://github.com/SyntaxArc/ArchiPy/pull/622)
    - `VAULT`: `APPROLE`, `KUBERNETES`, `USERPASS`, `LDAP`, `OKTA`, `JWT_AUTH`, `AWS`, `AZURE`, `GCP`, `GITHUB`,
      `CERT`, `TLS`, `HTTP`, `TOKEN_RENEWAL`
    - `SCYLLADB`: `TLS`, `RETRY`, `RECONNECTION`, `SPECULATIVE_EXECUTION`, `PREPARED_CACHE`, `HEARTBEAT`,
      `REPLICATION`
    - `TEMPORAL`: `TLS`, `WORKER`, `CLIENT_RETRY`, `KEEP_ALIVE`, `WORKFLOW`, `ACTIVITY`, `RETRY`
    - `REDIS`: `CLUSTER`, `SENTINEL`, `TLS`, `RETRY`
    - `ELASTIC`: `AUTH`, `TLS`, `RETRY`, `SNIFFING`
    - `SQLALCHEMY`: `POOL`, `COUNT_CACHE`
    - `AUTH`: `JWT`, `TOTP`, `RATE_LIMITS`, `PASSWORD_POLICY`
    - `KEYCLOAK`: `ADMIN`, `TLS`, `TOKEN_VALIDATION`
    - `EMAIL`: `TLS`, `POOL`, `ATTACHMENTS`
    - `GRPC`: `TLS`, `STUB_TLS`
    - `KAFKA`: `SASL`, `SSL`
    - `UVICORN`: `TLS`, `WEBSOCKET`, `LIMITS`
    - `FASTAPI`: `CORS`, `GZIP`, `TRUSTED_HOST`, `HTTPS_REDIRECT`
    - `OTEL`: `PUSHGATEWAY`

## Changed

### Configs - FastAPI

- **Form Limit Keys** - Name the `FASTAPI.FORM_LIMITS` fields `MAX_FIELDS`, `MAX_FILES`, and `MAX_PART_SIZE`, so
  environment variables such as `FASTAPI__FORM_LIMITS__MAX_FIELDS` work. [#620](https://github.com/SyntaxArc/ArchiPy/pull/620)

## Fixed

### Tests - Kafka

- **Flaky Invalid Subscription Scenario** - Make the librdkafka thread count in the Kafka client scenarios ignore
  threads that exit while `/proc` is read, and count only threads created during the step.
  [#621](https://github.com/SyntaxArc/ArchiPy/pull/621)

## Deprecated

The flat settings that moved into a group still work and emit a `DeprecationWarning` that names the new path. They are
removed in 6.0.0. A value set on a group wins over the flat one. For example `REDIS.SSL` is now `REDIS.TLS.IS_ENABLED`,
`VAULT.APPROLE_ROLE_ID` is `VAULT.APPROLE.ROLE_ID`, and `AUTH.JWT_ISSUER` is `AUTH.JWT.ISSUER`.
