# 5.0.2 — 2026-08-31

[← 5.0.3](5.0.3.md) | [5.0.1 →](5.0.1.md) | [↑ 5.x series](index.md)


## Added

### Helpers - OpenTelemetry

- **Initialization order documentation** - New "Initialization Order" section in the
  observability tutorial covering `OtelUtils.init_otel_if_needed(config)` at bootstrap.
    - Documents calling it right after `BaseConfig.set_global(config)`, before the DI
      container constructs adapters
    - Warns about permanent telemetry gaps when adapters are built first (SQLAlchemy
      engines, Confluent Kafka producers/consumers, Cassandra/ScyllaDB sessions,
      pre-init log records)
    - Clarifies which paths recover automatically via the global proxy providers and
      class-level instrumentor patches (Redis, requests, httpx, Elasticsearch)

## Dependencies

- **wrapt** - Refreshed `uv.lock` to wrapt 2.4.0.
