# 5.29.1 — 2026-11-14

[← 5.29.0](5.29.0.md) | [↑ 5.x series](index.md)

## Fixed

### Adapters - SQLAlchemy

- **Atomic Session Cleanup** - Outermost synchronous and asynchronous atomic blocks always release their sessions, including when cancellation or an interrupted rollback leaves a transaction open. Synchronous cleanup removes the session registry entry even if closing the session raises. [PR #582](https://github.com/SyntaxArc/ArchiPy/pull/582)

## Tests

### Tests - SQLAlchemy

- **Interrupted Cleanup Regressions** - Add coverage for repeated asynchronous cancellation, a second cancellation during rollback, and an interrupted synchronous rollback. Verify that sessions close and registry entries are removed. [PR #582](https://github.com/SyntaxArc/ArchiPy/pull/582)

## Chore

### Chore - Typing

- **Type Checker Compatibility** - Update diagnostic names in strict typing rules and targeted suppressions for the newer ty release. [PR #581](https://github.com/SyntaxArc/ArchiPy/pull/581), [issue #580](https://github.com/SyntaxArc/ArchiPy/issues/580)

## Dependencies

### Dependencies - Workspace

- **Dependency Minimums and Lockfile** - Refresh locked dependencies and raise minimum versions for Pydantic Settings, FastAPI, Pydantic AI, boto3, psycopg, PyMySQL, Temporal, and development and documentation tools. Includes [PR #581](https://github.com/SyntaxArc/ArchiPy/pull/581), [issue #580](https://github.com/SyntaxArc/ArchiPy/issues/580), and commit `e45cf5d1`.
