# 5.29.0 — 2026-11-09

[← 5.28.0](5.28.0.md) | [↑ 5.x series](index.md)

## Added

### Helpers - Keycloak Organization Scope

- **Organization Resolution** - Added `KeycloakUtils` to resolve the organization a Keycloak 26 access token selected.
    - `parse_organization_uuids` reads the `organization` claim and skips malformed entries without raising
    - `resolve_selected_organization_uuid` fails closed on a malformed claim, returns `None` for the `organization:*` scope or no organization, and raises `PermissionDeniedError` for several organizations
    - `require_selected_organization_uuid` raises `PermissionDeniedError` when no organization is selected
    - Works on verified claims, needs no extra and does not import Keycloak

### Adapters - Keycloak

- **Organization Dependency** - Added the `require_selected_organization` FastAPI dependency in `archipy.adapters.keycloak.auth`.
    - Reads the token claims from `AuthContextManager` instead of the deprecated `request.state.token_info`

## Tests

### Tests - Keycloak

- **Organization Scope** - Added BDD scenarios for the helper rules and the FastAPI dependency; they need no containers.
