## Fixed

### Adapters - SQLAlchemy

- **Nested Atomic Rollback** - A failed nested `atomic()` call now rolls back the outer transaction.
    - Nested calls join the outer transaction instead of opening a savepoint; the session is marked rollback-only on failure
    - An outer block that swallows the nested error raises `DatabaseTransactionError` and commits nothing
    - The nested atomic scenarios and the concepts guide document the new behavior
