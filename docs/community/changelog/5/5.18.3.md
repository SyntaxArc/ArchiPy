# 5.18.3 — 2026-10-20

[← 5.19.0](5.19.0.md) | [5.18.2 →](5.18.2.md) | [↑ 5.x series](index.md)

## Fixed

### Adapters - Email

- **Import Without jinja2** - `archipy.adapters.email.adapters` no longer fails with `ModuleNotFoundError: No module named 'jinja2'` when `jinja2` is not installed.
    - `jinja2` is imported only when an email template is rendered, so plain emails need no extra package
    - Rendering a template without `jinja2` raises `ConfigurationError` with an install hint

## Tests

### Tests - Adapters

- **Optional Dependencies** - Added `features/optional_dependencies.feature`, which builds an email message with `jinja2` blocked.
