# 5.32.0 — 2026-11-21

[← 6.0.0](../6/6.0.0.md) | [5.31.2 →](5.31.2.md) | [↑ 5.x series](index.md)

## Added

### Configs - FastAPI

- **Request Body and Form Limits** - Set `FASTAPI.MAX_BODY_SIZE` to cap the total request body in bytes, including uploaded files and multipart overhead. Use `FASTAPI.FORM_LIMITS` to limit the number of fields and files and the size of each text field. FastAPI uses its defaults for omitted form settings. Set the limits as `FASTAPI.FORM_LIMITS.MAX_FIELDS`, `MAX_FILES`, and `MAX_PART_SIZE`, or with environment variables such as `FASTAPI__FORM_LIMITS__MAX_FIELDS`. Oversized bodies return HTTP 413, and form parsing limit violations return HTTP 400. [#610](https://github.com/SyntaxArc/ArchiPy/pull/610), [#620](https://github.com/SyntaxArc/ArchiPy/pull/620)

### Configs - Nested Settings

- **Grouped Settings** - Related settings now live in nested groups of their section. Groups reject unknown keys, use
  UPPER_CASE fields, and name every on/off switch `IS_ENABLED`. Set them in code or with the `__` delimiter, for
  example `REDIS__TLS__IS_ENABLED=true`. The flat settings they replace still work, emit a `DeprecationWarning` that
  names the new path, and are removed in 6.0.0; a value set on a group wins over the flat one. For example
  `REDIS.SSL` is now `REDIS.TLS.IS_ENABLED`, `VAULT.APPROLE_ROLE_ID` is `VAULT.APPROLE.ROLE_ID`, and
  `AUTH.JWT_ISSUER` is `AUTH.JWT.ISSUER`. [#622](https://github.com/SyntaxArc/ArchiPy/pull/622)
    - `VAULT`: `APPROLE`, `KUBERNETES`, `USERPASS`, `LDAP`, `OKTA`, `JWT_AUTH`, `AWS`, `AZURE`, `GCP`, `GITHUB`,
      `CERT`, `TLS`, `HTTP`, `TOKEN_RENEWAL`
    - `SCYLLADB`: `TLS`, `RETRY`, `RECONNECTION`, `SPECULATIVE_EXECUTION`, `PREPARED_CACHE`, `HEARTBEAT`,
      `REPLICATION`
    - `TEMPORAL`: `TLS`, `WORKER`, `CLIENT_RETRY`, `KEEP_ALIVE`, `WORKFLOW`, `ACTIVITY`, `RETRY`
    - `REDIS`: `CLUSTER`, `SENTINEL`, `TLS`, `RETRY`
    - `ELASTIC`: `AUTH`, `TLS`, `RETRY`, `SNIFFING`
    - `SQLALCHEMY`: `POOL`, `COUNT_CACHE`
    - `AUTH`: `JWT`, `TOTP`, `RATE_LIMITS`, `PASSWORD_POLICY`
    - `KEYCLOAK`: `ADMIN`, `TLS`, `TOKEN_VALIDATION`
    - `EMAIL`: `TLS`, `POOL`, `ATTACHMENTS`
    - `GRPC`: `TLS`, `STUB_TLS`
    - `KAFKA`: `SASL`, `SSL`
    - `UVICORN`: `TLS`, `WEBSOCKET`, `LIMITS`
    - `FASTAPI`: `CORS`, `GZIP`, `TRUSTED_HOST`, `HTTPS_REDIRECT`
    - `OTEL`: `PUSHGATEWAY`

## Changed

### Chore - Documentation

- **Zensical Documentation Builds** - Use Zensical for local docs commands, CI, GitHub Pages, and Read the Docs. Move the site configurations to the repository root. [#613](https://github.com/SyntaxArc/ArchiPy/pull/613), [#616](https://github.com/SyntaxArc/ArchiPy/pull/616)

## Fixed

### Tests - Kafka

- **Flaky Invalid Subscription Scenario** - Make the librdkafka thread count in the Kafka client scenarios ignore threads that exit while `/proc` is read and count only threads created during the step. [#621](https://github.com/SyntaxArc/ArchiPy/pull/621)

### Tests - Coverage

- **Coverage Failure Exit Status** - Make the parallel Behave runner exit with an error when combining coverage data, reporting coverage, or writing the XML report fails. [#609](https://github.com/SyntaxArc/ArchiPy/pull/609)
