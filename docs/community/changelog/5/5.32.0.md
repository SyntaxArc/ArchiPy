# 5.32.0 — 2026-11-21

[← 5.31.2](5.31.2.md) | [↑ 5.x series](index.md)

## Added

### Configs - FastAPI

- **Request Body and Form Limits** - Set `FASTAPI.MAX_BODY_SIZE` to cap the total request body in bytes, including uploaded files and multipart overhead. Use `FASTAPI.FORM_LIMITS` to limit the number of fields and files and the size of each text field. FastAPI uses its defaults for omitted form settings. Oversized bodies return HTTP 413, and form parsing limit violations return HTTP 400. [#610](https://github.com/SyntaxArc/ArchiPy/pull/610)

## Changed

### Chore - Documentation

- **Zensical Documentation Builds** - Use Zensical for local docs commands, CI, GitHub Pages, and Read the Docs. Move the site configurations to the repository root. [#613](https://github.com/SyntaxArc/ArchiPy/pull/613), [#616](https://github.com/SyntaxArc/ArchiPy/pull/616)

## Fixed

### Tests - Coverage

- **Coverage Failure Exit Status** - Make the parallel Behave runner exit with an error when combining coverage data, reporting coverage, or writing the XML report fails. [#609](https://github.com/SyntaxArc/ArchiPy/pull/609)

## Tests

### Tests - Container Images

- **Test Image Updates** - Update StarRocks to `4.1.8`, ScyllaDB to `2026.3.6`, and Mailpit to `v1.34.0`. [#601](https://github.com/SyntaxArc/ArchiPy/pull/601)

## Chore

### Chore - CI and Publishing

- **Python 3.15 CI** - Run lint, documentation checks, tests, and package builds on Python 3.14 and 3.15 in Astral uv containers. Publish the distributions built on Python 3.14 after both builds pass. [#597](https://github.com/SyntaxArc/ArchiPy/pull/597)
