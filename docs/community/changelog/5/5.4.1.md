## Tests

### Tests - Redis

- **Vector range search uses FLAT** - Radius KNN BDD builds the index with
  `VectorAlgorithm.FLAT` instead of the default HNSW.
    - Optional `and algorithm FLAT|HNSW|SVS-VAMANA` on the given-index step
    - Matches RediSearch / fakeredis 2.38 range-query behavior

### Tests - Configuration

- **Keycloak test image** - Updated `KEYCLOAK__IMAGE` from `keycloak/keycloak:26.7.3`
  to `keycloak/keycloak:26.7.4`.
- **Elasticsearch test image** - Updated `ELASTIC__IMAGE` from
  `elastic/elasticsearch:9.5.3` to `elastic/elasticsearch:9.5.4`.
