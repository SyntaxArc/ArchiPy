    5.26.0 — 2026-11-02¶

    ← 5.25.0 | ↑ 5.x series

    Added¶

    Adapters - Kafka¶

    • Transactions - begin_transaction(), commit_transaction() and abort_transaction() on the sync and async producers.
      • A producer with TRANSACTIONAL_ID calls init_transactions() when it is created
      • TRANSACTION_TIMEOUT_MS must cover the delivery timeout; the adapter sets a safe default otherwise

    Adapters - Redis¶

    • Close - close() on the sync and async adapters closes the write, read-only and RediSearch clients and their pools.
      • The sync and async context managers call it; both classes use the same method name

    Adapters - ScyllaDB¶

    • Query Options - batch_execute() accepts batch types and bound parameters; exists() stops at the first row and select() takes an optional limit.
    • Prepared Statements - The CRUD helpers run as prepared statements, and the prepared statement cache is keyed by keyspace.
    • TLS Options - TLS_SERVER_NAME and session cache settings build the cluster ssl_context.

    Adapters - MinIO¶

    • Batch Delete - remove_objects() deletes in batches of at most 1000 keys and reports the failed keys.
    • Presigned URLs - Expiry is validated before the URL is generated.

    Adapters - Email¶

    • Sender Address - FROM_ADDRESS sets the From header when USERNAME is not a real address.

    Changed¶

    Configs - Secrets¶

    • SecretStr - Redis, Keycloak, MinIO, Vault and SQLAlchemy password and token fields are pydantic.SecretStr.
      • repr(), str() and model_dump() mask them; adapters read the real value with get_secret_value()
      • POSTGRES_DSN is a non-string secret and keeps Field(repr=False)

    Adapters - Redis¶

    • Async Close Name - The async adapter exposes close(), not aclose(), so sync and async classes share method names.

    Adapters - ScyllaDB¶

    • Plaintext Warning - A config with credentials and TLS disabled, or hostname checks disabled, logs a warning.

    Fixed¶

    Adapters - Kafka¶

    • Admin Results - create_topic() and delete_topic() check the result futures.
    • Error Mapping - Timeouts, transport failures, authentication and invalid arguments map by librdkafka error code instead of a message substring.
    • Async Consumer - A failed first subscribe no longer leaves the consumer unsubscribed.
    • Client Leaks - The sync consumer closes its client when init validation or subscribe fails.
    • Fatal Errors - Fatal consumer errors are raised instead of only logged.
    • Delivery Callbacks - The sync producer serves delivery callbacks outside flush().
    • Secret Logging - A delivery failure no longer logs the message payload.
    • Empty Key - A missing key is sent as None, not empty bytes.
    • Config Validation - Security protocol and SASL mechanism are validated enums rather than free strings.
    • Hardening - Low-severity fixes for client options, topic admin and docs.

    Adapters - Redis¶

    • Byte Values - Bytes keys, fields and values are stored as-is instead of their b'..' repr.
    • Range Search - filter_expr is combined with AND instead of OR.
    • Text Scorer - SearchQueryDTO.text_scorer is applied.
    • Sentinel - DATABASE and HEALTH_CHECK_INTERVAL are honoured in sentinel mode.
    • RESP3 Aggregate - The async aggregate() normalises RESP2 and RESP3 replies.
    • Async Iteration - scan_iter() and sscan_iter() are directly async-iterable; the awaited form still works.
    • Injection - RediSearch query values are escaped, closing an injection path through DTO fields.
    • Docs and Mocks - Cache error docs, cluster mocks, upsert_hash() and config hardening are corrected.
    • Hardening - Mock cluster operations use CRC16 slots and return a real topology.

    Adapters - SQLAlchemy, PostgreSQL, MySQL and StarRocks¶

    • Nested Atomic - A failed nested atomic call no longer closes the outer transaction.
    • Password Quoting - DSNs quote passwords with /, # and ?, and errors no longer echo them.
    • DSN Options - PostgreSQL DSN query parameters are applied and percent-encoded credentials are decoded.
    • Session Registry - Async atomic blocks release their session registry entry.
    • Secret Handling - Passwords stay out of repr, the DSN string and the session manager singleton key.
    • Expired Entities - Entities returned from an atomic block are no longer expired and detached.
    • Error Classification - Driver errors are classified by driver message instead of a substring of the SQL.
    • Hardening - SSL root certificate warnings, StarRocks timeouts, SQLite foreign keys and LIKE escaping.
    • Tutorials - Entity and FastAPI examples that failed are corrected.

    Adapters - Keycloak¶

    • FastAPI Guards - The ownership check runs when only one resource argument is set.
    • Cache Clearing - clear_all_caches() works without admin credentials and no longer logs in.
    • Error Mapping - Errors map by status code, and 5xx upstream messages are no longer exposed.
    • Cache TTL - REMOTE_CACHE_TTL_SECONDS=0 disables caching.
    • Async Admin - Admin token refresh runs off the event loop behind a lock.
    • JWKS - Keys are cached instead of fetched on every token check; outages no longer become 401.
    • Token Validation - Local verification checks issuer, audience and token type.
    • Hardening - Leeway, error detail and secret repr fixes, plus stale docs.

    Adapters - MinIO¶

    • Cache Invalidation - Writes clear stat, policy, versioning and version-list caches, and cached results are copied.
    • Error Mapping - Botocore timeout and connection errors map to specific ArchiPy errors.
    • Streaming - get_object_stream() closes the body and enforces a size cap.
    • Not Found - A missing object is reported as an object, not a missing bucket.
    • Copy Source - The source key stays literal, so a key cannot choose a version.
    • Hardening - Credentials stay out of repr, an endpoint scheme is accepted and insecure settings warn.

    Adapters - Vault¶

    • Retries - Retries no longer replay POST, PUT or DELETE, and an outage maps to UnavailableError.
    • Auto Renew - AUTO_RENEW_TOKEN handles non-renewable and non-expiring tokens and re-logs in when needed.
    • Hardening - Cached dict mutation, VERIFY_SSL parsing and secret repr fixes.

    Adapters - Temporal¶

    • Activity Names - Each BaseActivity subclass registers under its own name.
    • Retryability - Transient ArchiPy errors remain retryable, while 4xx errors stay non-retryable.
    • List Workflows - list_workflows() is wrapped by _mapped_errors.
    • Error Data - Raw SDK errors and non-retryable error text stay out of failures and additional_data.
    • Workers - stop_worker() keeps a worker that is still running tracked.
    • Hardening - Grace period docs, start readiness and runtime singleton warnings.

    Adapters - Email¶

    • Pool Leak - A failed get_connection() no longer leaks a pool slot or hangs send_email.
    • STARTTLS - Credentials are not sent in clear text, and a stripped STARTTLS upgrade is caught.
    • Config Validation - Pool, retry and timeout settings are validated, and the sender address is configurable.
    • Hardening - Retry duplicates, header errors and URL attachments.

    Adapters - Parsian and Saman¶

    • Secret Logging - Login accounts, tokens and card data stay out of debug logs.
    • Error Mapping - Network failures map to UnavailableError and gateway 4xx replies to validation errors.
    • WSDL Timeout - Parsian bounds WSDL loading with the configured timeout.
    • Lifecycle - Both adapters expose close(), use configured timeouts and validate the Neo-PG redirect URL.
    • Docs - Callback examples, endpoints and error types are corrected.

    Adapters - Elasticsearch¶

    • Error Mapping - Client failures map to ArchiPy errors, and retries no longer replay non-idempotent writes.
    • Config Validation - Plaintext transport with credentials and partial credential pairs are rejected.

    Helpers - Decorators¶

    • TTL Cache - ttl_cache no longer shares one cache across all instances.

    Tests¶

    Tests - Adapters¶

    • Audit Coverage - Regression scenarios for the Redis, Kafka, Keycloak, MinIO, Vault, Temporal, email, SQL and payment fixes above, including mock cluster operations and secret masking.
